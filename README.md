# Jeffrey Lee engineering portfolio

Open `index.html` to preview the website. The site uses plain HTML and CSS with local assets.

## Publish with GitHub Pages

1. Create a public repository on GitHub. To publish at `https://YOUR-USERNAME.github.io/`, name the repository `YOUR-USERNAME.github.io`. A repository named `portfolio` will publish at `https://YOUR-USERNAME.github.io/portfolio/`.
2. Unzip the download. Upload or commit its contents to the repository root on the `main` branch. Make sure `index.html`, `styles.css`, and the `assets` directory are at the root.
3. Open **Settings → Pages**. Set **Source** to **Deploy from a branch**, choose **main** and **/(root)**, then click **Save**.
4. When the deployment succeeds, open the address shown under **Settings → Pages**. That is the link to send to employers.

Edit `index.html` to update the homepage and the individual project HTML files to update case studies. Replace `assets/jeffrey-lee-resume.pdf` to update the downloadable résumé.
