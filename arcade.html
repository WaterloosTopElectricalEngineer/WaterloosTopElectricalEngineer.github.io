Hardware & fabrication

Raspberry Pi Arcade Cabinet

Building the cabinet

I laser-cut plywood panels for the shell and 3D-printed brackets to join them. We fitted a monitor into the cabinet, then I wired the joysticks and illuminated buttons for two players.

Setting up the games

We flashed RetroPie onto a microSD card and used it to boot the Raspberry Pi. RetroPie provided the game menu and emulators. We configured the wired controls for both players so the cabinet could run local multiplayer games at school events.
